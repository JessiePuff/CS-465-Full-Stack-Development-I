# CS-465-Full-Stack-Development-I
Full Stack with MEAN
In this full stack MEAN project, I worked with two different frontend approaches: traditional Express HTML/JavaScript and an Angular single‑page application (SPA). The customer‑facing site uses Express to render Handlebars templates on the server, following a simple request–response model. In contrast, the admin interface is a fully client‑side Angular SPA that loads once and updates dynamically through components and services. This creates a smoother, more interactive experience for administrators, while Express provides a straightforward structure for public pages. The backend uses a NoSQL MongoDB database because its flexible, JSON‑like document structure integrates naturally with JavaScript and supports scalable data storage for trips, users, and reservations.

JSON plays a key role in connecting the frontend and backend. Unlike JavaScript, JSON is a data format rather than executable code, and it allows the Angular SPA, Express API, and MongoDB database to exchange information consistently. Throughout development, I refactored code to improve clarity and efficiency—for example, consolidating repeated logic into Angular services and cleaning up Express controllers. Reusable UI components, such as trip cards and form elements, helped reduce duplication and made the admin interface easier to maintain.

Testing the application required verifying API endpoints for GET, POST, and PUT requests and ensuring that data flowed correctly from Angular to Express to MongoDB. Adding authentication introduced additional testing challenges, since protected routes required valid JSON Web Tokens (JWTs). This reinforced my understanding of how methods, endpoints, middleware, and security work together in a full stack system.

Overall, this course strengthened my full stack development skills and helped me grow as a developer. I gained hands‑on experience with the MEAN stack, RESTful APIs, authentication, debugging, and architectural planning. These skills make me a more competitive candidate in the software development field and better prepared for real‑world full stack engineering roles.
